会话状态流转（本阶段规则）
点 + 选 CLI / PTY ──► [草稿] 不落库 / 不进列表 / 不起进程（全局仅 1 个，切走即丢弃）
        │ 发出第一条消息（携带 model / permMode / cwd / projectId / requirementId）
        ▼
   [活跃] ── CLI 退出 / 重启 ──► [已断开 · 可恢复] ◄──────────┐
     │                              │                        │ 取消归档
     │ 归档（hover）                  │ 归档                    │ （touch 重置活跃时间）
     ▼                              ▼                        │
   [已归档] 移出默认列表、保留 native_session_id ─────────────┘
     │  │
     │  └── 删除 ──► [已移除] 二次确认 → 终止进程 + 删行 + unlink 收敛 + 切激活
     │                （不删 CLI 原生 transcript、不撤销）
     └── 自动归档：设置开关(默认关) + N 天(默认 30，1–365)
          启动 / 改设置时扫描；跳过 running / waiting / 进程存活（含空闲终端）与已归档
          基准 COALESCE(last_active_at, created_at)
与既有原型的差异：新增「草稿」态（stage1–4 点 + 即落库）；新增「归档 / 已归档 / 已移除」三态与设置面板； 顶栏「设置」由 2 项浮层升级为 modal；侧栏会话行新增 hover 操作；其余布局、配色、徽标、"已断开"引导条保持既有形态。
必须一致项：暗色 token、顶栏 42px、侧栏分组（项目 / 结构化会话 / PTY 终端 / 底部入口）、会话行色点与徽标、恢复引导条文案与按钮。 可调整范围：设置 modal 宽度与分区间距、草稿提示文案措辞、hover 操作按钮的具体图标/文字、已归档分组的展开动画。
